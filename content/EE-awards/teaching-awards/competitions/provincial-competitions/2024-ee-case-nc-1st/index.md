### 奖项概述

在第十一届全国高校电工电子基础课程实验教学案例设计竞赛华北赛区中，学院教师董云霞、丰俊、陈艳波设计的实验教学案例《回转器电路的研究》荣获**省部级一等奖**。

案例围绕电路回转特性、反馈控制与器件参数匹配展开教学设计，引入“问题驱动 + 探究实验 + 模拟仿真”混合式教学方法，强化学生对电路机理的理解与实验创新能力。

### 获奖信息

| 项目 | 内容 |
|------|------|
| 奖项名称 | 全国高校电工电子基础课程实验教学案例设计竞赛（华北赛区） |
| 奖项等级 | 一等奖 |
| 案例名称 | 回转器电路的研究 |
| 获奖人 | 董云霞、丰俊、陈艳波 |
| 主办单位 | 高等学校国家级实验教学示范中心联席会电子学科组 |
| 获奖级别 | 省部级 |
| 获奖时间 | 2024年6月 |
